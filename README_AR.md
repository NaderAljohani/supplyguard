# حارس الإمداد: SupplyGuard Saudi

لوحة تحليلات لتقييم تعرض واردات السعودية من الأرز والقمح والشعير والذرة والسكر
لمخاطر التركّز وتغيرات الواردات والأسعار والخدمات اللوجستية وحركة الموانئ.
يعرض مؤشراً مركباً، وكشف الشذوذ، وتنبؤاً تجريبياً بقيمة المؤشر، ومحاكاة سيناريوهات.

![مدخلات محاكي السيناريوهات ومقارنة المؤشر قبل التغيير وبعده](docs/images/scenario-demo.gif)

عرض مدته 10 ثوانٍ من محاكي السيناريوهات ببيانات اللقطة التاريخية وسيناريو
تصاعد ضغط البحر الأحمر. يعرض تغيراً افتراضياً في المؤشر تحت الافتراضات المختارة.

## التشغيل

استخدم Python 3.13 من جذر المستودع:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt
python -m streamlit run app/streamlit_app.py
```

تتضمن النسخة لقطة بيانات ومخرجات جاهزة للعرض. لإعادة توليد المخرجات:

```powershell
python run_pipeline.py
python scripts/update_data_manifest.py
```

لا يلزم مفتاح لتشغيل التحليل أو الواجهة. طبقة التوصيات النصية عبر Gemini اختيارية.

## تجربة التحليل

ابدأ بنظرة عامة على السلع، ثم افحص تركّز الموردين ومكونات المؤشر. تعرض صفحة
السيناريوهات أثر الافتراضات التي تدخلها على قيمة المؤشر. تبقى الحسابات محلية،
ويقتصر دور النموذج الاختياري على شرح النتائج نصياً.

## ما الذي تثبته النتائج؟

المؤشر مركب من أوزان افتراضية، وليس احتمالاً مثبتاً لتعطل الإمداد. البيانات
تاريخية وليست حية. المحاكاة تعيد حساب المؤشر تحت افتراضات المستخدم، ولا تثبت
وفورات مالية أو تأثيراً سببياً.

اختيار نموذج التنبؤ يعتمد فترة تحقق أسبق، ثم يقاس على فترة اختبار منفصلة.
خط الأساس داخل المنافسة، والأشهر المفقودة لا تعامل كأشهر متتالية. بعض عينات
الاختبار صغيرة جداً، ولذلك تبقى التنبؤات تجريبية. راجع
[النتائج](docs/EVALUATION.md) و[البيانات](docs/DATA.md).

```powershell
python scripts/check_release.py
python -m pytest -q
```

لم يُختر ترخيص مفتوح المصدر للكود بعد. راجع [الدليل الإنجليزي](README.md).

تُشغّل [الاختبارات الآلية](https://github.com/NaderAljohani/supplyguard/actions/workflows/ci.yml)
على Windows وLinux، وتشمل حدود التنبؤ وخط الأساس والأشهر المفقودة وصفحات الواجهة.
