# Data snapshot and attribution

The bundled derived extracts were supplied with the original local project.
They combine UN Comtrade bilateral trade, World Bank Pink Sheet price proxies,
World Bank LPI, and IMF PortWatch maritime indicators. `data/raw/` is the fixed
input snapshot for this publication copy; `data/processed/` and `data/outputs/`
are regenerated by `python run_pipeline.py`.

Original service links:

- UN Comtrade: https://comtradeplus.un.org/
- World Bank commodity markets: https://www.worldbank.org/en/research/commodity-markets
- World Bank LPI: https://lpi.worldbank.org/
- IMF PortWatch: https://portwatch.imf.org/

These links identify the providers; the project has no live ingestion or update
guarantee. Reproducing the supplied derived extracts directly from provider
downloads requires upstream preparation that is not fully scripted here.

Trade coverage is 2018-01 through 2025-07, with gaps and varying supplier
coverage. The event CSV contains curated temporal annotations, including markers
outside trade coverage. It is not a ground-truth disruption dataset, and the
event claims were not independently verified during repository preparation.
The feature pipeline uses supplied historical proxies; real-time availability
and publication lags remain limitations.

The publication data manifest records file hashes for the included snapshot.
Attribution does not establish an open license for all derived extracts.
Provider terms and the origin of any manually prepared fields need to be
checked before redistributing or using the data beyond this project. See
[license status](../LICENSE_NOTICE.md).
